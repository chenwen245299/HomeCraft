Codex · 时间窗口额度

读取实际返回的短期、每周和月度窗口；服务未返回的窗口显示“未提供”。

不要和正在使用的电脑客户端共用轮换刷新令牌；可用一次性授权工具创建独立会话。
Claude Code · 短期 / 每周额度

订阅额度使用未公开的客户端查询接口，可能变化或限流；额外使用的月度预算属于金额，不等同于订阅月额度。

此设备不提供第三方 Claude 登录。凭据需来自你自己的官方客户端授权；接口兼容性、权限和有效期受服务方控制。
DeepSeek 官方 API · 余额

官方公开接口返回 CNY / USD 余额，未提供周、月套餐剩余比例。此处显示余额，不推算月额度。

配网窗口通常在 10 分钟后关闭。之后可在设备“网络设置”页三击 BOOT 再打开。网页登录需要 Wi-Fi 热点密码和屏幕配网码。

当前状态

连接后显示各服务状态。
登录过期、限流、网络错误会分别显示，旧数据保留并标记过期；重试不会自动消耗模型额度。

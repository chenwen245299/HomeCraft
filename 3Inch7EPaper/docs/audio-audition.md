# 喇叭试听记录

2026-10-25，用户确认已安装外接喇叭并接好 USB，授权播放复杂一些的音乐检查效果。本轮使用独立临时试听固件；日常仪表盘源码没有加入播放器，最终恢复状态见 `3Inch7EPaper/artifacts/audio-audition-20261025-validation.json`。

## 音频与硬件

- 原创合成器乐 28 秒，包含钢琴音色旋律、贝斯、和弦、琶音及鼓组；不是商业录音。44.1 kHz、16 位单声道，播放时复制至两个 I²S 声道。初轮 PCM 峰值 -8 dBFS、RMS 约 -23.19 dBFS；最终版本仅提高电平，峰值 -1 dBFS、RMS 约 -16.19 dBFS，首尾淡入淡出。
- 使用乐鑫官方 `esp_codec_dev` 1.6.2，源码固定到 `espressif/esp-adf` 提交 `1c7aa251b937742f1308c4f3b9e7587034bc5fb7`。仅配置 DAC 播放，不采集麦克风。
- ES8311 地址 `0x18`；MCLK/BCLK/WS/DOUT 分别 GPIO13/14/47/48，功放控制 GPIO39。GPIO4/5/6 保持禁用、无上下拉和中断；不初始化 IMU 中断。
- 对照官方原理图，Audio_VCC 为 ALDO1，功放 VDD 为 VCC3V3。试听临时读改写 PMU `0x92` 与 `0x90[0]`，将 ALDO1 配置为 3.3 V；播完恢复原寄存器并读回核对。没有更改充电参数。
- 官方原理图的 GPIO39 同时列有 AudioCTR_PIN 与 AXIS_INT1；IMU INT1 路径的 R9 标 NC。本次独立程序只用 GPIO39 控制功放，不据此宣称已逐一核实用户 PCB 修订版或所有 IMU 中断连接。

## 实测边界

初次音量设置 50/100 时，28 秒数据写入完整，用户反馈没有声音。加入三声短音并将音乐音量设为 75/100 后，用户确认能听到，但音量太小；已确认实物发声，不能把前一轮单纯的软件写入成功当作声音确认。

随后同一段音乐按 85→90→95/100 渐增，用户仍认为偏小。最终将音源从 -8 提高到 -1 dBFS，并按 85→95→100/100 渐增，分别在开始、2 秒及 8 秒切换。相较上一轮最高档，合计增加约 9.5 dB。用户明确确认“音量够了，声音正常”。软件音量值是官方驱动设置，不能等同为功率百分比或声压。

实测读回 PA=1、ALDO1=0x1C、ES8311 DAC 取消静音（0x31=0x00）、DAC 开启（0x12=0x00），I²S 为 44.1 kHz／16 位／双声道。前两轮完成 1,234,800 帧并恢复原音频供电寄存器；后续完成及恢复证据记录在对应验证 JSON。

用户随后要求知名中文歌曲原版人声测试。选用 Apple 公开目录中邓丽君《月亮代表我的心》的官方约 30.01 秒试听（trackId 1440659986），转换为同规格 PCM，并沿用已确认的音量。只测试官方预览片段，不把它描述成完整歌曲；没有提取或输出歌词，歌曲音频与含该片段的临时固件不进入项目发行包。实测完整播放 1,323,440 帧、恢复音频供电寄存器，用户确认“人声清楚，音量合适”。[歌曲官方页面](https://music.apple.com/tw/album/1440659594?i=1440659986)。

## 恢复与复用

临时程序不初始化 NVS、SD、BLE、Wi-Fi 或屏幕；只等待 USB 的 PLAY 指令播放一次。STOP 或 BOOT 短按可停止，播完静音并关闭功放。试听期间没有环境采样和 SD 分钟落盘，不填补缺测数据。

写入前已核对板上应用与归档 0.2.34 完全一致，并保存权限 600 的私有回退备份。临时固件仅写入 0x10000 应用区；恢复也只写原 factory 应用区，不擦除或重写 dashboard NVS。含配置的备份仅留本机，不能分享或进入发行包。

试听曲、合成源与诊断源码保存在 `3Inch7EPaper/artifacts/audio-audition-20261025/`；官方依赖位于本次临时构建目录，未加入日常固件组件。后续正式音乐功能仍需单独实现播放入口、曲目读取及正常关机清理，不能把本轮一次性试听当作日常播放器已经交付。

# USB 插拔与电源标志快速局刷

固件0.2.35按用户2026-10-25要求，将电源变化从普通30秒采样和30–60秒显示合并中独立出来。部署与实体插拔验证以 `3Inch7EPaper/artifacts/power-events-0235-validation.json` 为准。

## 行为

- 外接USB有效时，顶部显示插头和USB；即使电池已满、不再充电，也保持外部供电标志。拔掉USB后显示PMU实际电量，未知为 `--`，不因为“通常已经充好”假定100%。
- 在既有10ms按键任务中，每100ms只读PMU `0x00`、`0x01` 的供电/电池/充电状态，连续稳定至少100ms后确认变化；错误或回弹重新等待，不发布猜测值。
- 确认供电变化后重新读取一次电量计；平时百分比仍随30秒温湿度/PMU采样更新。没有改充电参数、计量设置、PMU中断配置或其他引脚。
- 显示空闲、同页同方向且差分底图有效时，跳过普通合并等待，恢复上一成功帧后只重绘顶部104×32像素电源区域；通过原有双RAM差分驱动更新。预期空闲状态下约1秒可见，包含检测稳定等待和约0.7秒屏幕差分；不是零延迟。
- 正在全刷时等待当前操作结束；页面/方向改变、手动全刷及错误恢复保持原规则，不强行打断屏幕驱动。没有恢复旧打包矩形局刷，也不恢复周期全刷。
- 暂停状态也可更新电源标志。正文、传感器显示数值和已显示帧中的温湿度仍保留上一成功画面的值；单独刷电源不会把尚未画出的采样误报为已经显示，也不完成待处理的手动采样事务。
- 电源小更新不重置普通内容的30–60秒合并时钟。BOOT/PWR、温湿度、IMU、SD分钟日志、BLE安全及账户入口继续沿用原实现。

## 检查与诊断

`sh 3Inch7EPaper/tools/test_power_events.sh` 检查稳定时间、插拔回弹、PMU读失败、真实百分比及USB充满语义；768组页面/四方向/暂停状态/电源变化渲染检查核对完整画面与电源补丁一致，电源区域外无像素变化，正文采样变化不被带入。另通过64组环境/差分、140组主页字形及原手动采样/设备协议检查。

USB维护命令 `EPAPER_POWER_EVENTS` 读取RAM中最近8项source/shown事件，只含供电状态、百分比及单调时间；便于拔掉USB后重新接入时核对两次实际局刷。它不保存到NVS或SD，不含账户、PIN或配对秘密。`EPAPER_POWER`改为当次只读PMU查询，避免与主循环消费遥测队列竞争而误报未知。

源代码在 `3Inch7EPaper/main/power_events.c`、`3Inch7EPaper/main/board.c`、`3Inch7EPaper/main/main.c` 和 `3Inch7EPaper/main/dashboard.c`。Mac App无需更新。

## 实板结果与耗电边界

0.2.35已app-only写入并通过哈希；用户完成实际USB拔插，确认“两次都很快，显示正常，功能没问题”。RAM记录中，拔掉的稳定source事件为79031ms、显示完成79739ms，相隔708ms；插回为84917ms→85677ms，相隔760ms。上述时间从稳定确认开始计算，此外还有最多约200ms的轮询/稳定等待，不是从物理插头接触瞬间测量。原绑定认证、真实同步、SD1366→1368/write_ok=1及partial=1/ready=1保留。

用户随后询问耗电。快速源检测确实新增约20次I²C寄存器读取/秒，复用既有按键任务，不增加独立定时唤醒任务；没有每100ms刷新屏幕或轮询完整电量计。每次实际插拔多一次必要的电源差分。尚未测量本增量的整板电流和续航差值，不能将这条设计描述成零额外耗电，也不能给出未经测量的功耗百分比。

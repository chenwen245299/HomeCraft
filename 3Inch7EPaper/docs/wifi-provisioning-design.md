# 便捷、安全的配网设计

记录日期：2026-10-20。本文是针对用户反馈整理的下一版设计，**不是当前固件已经实现的功能清单**。当前固件的实际行为仍见 README 与 `usage-providers.md`。

后续选择：用户愿意使用乐鑫官方应用，当前已改为优先实现 BLE + Security 2，见 [官方蓝牙配网记录](ble-provisioning.md)。本文保留的默认网页流程是较早的备选设计，二维码自动弹页和网页实体授权会话仍未实现，不能据此指导当前固件。

## 选择

推荐以 **临时加密热点 + AP/STA 并行 + 扫码连接 + 手机配网页面 + 实体确认** 为默认入口。目标是手机不用安装应用、无需电脑中转，也不必抄写热点密码和网页配网码。

| 方案 | 手机操作 | 适用判断 |
| --- | --- | --- |
| SoftAP + 网页 | 扫码加入热点，打开页面，选择网络并输入密码 | 本项目默认；兼容普通手机浏览器，可复用现有实现 |
| BLE + 乐鑫官方配网应用 + Security 2 | 应用扫码或发现设备，输入 Wi-Fi 密码 | 更适合不希望手机切换 Wi-Fi、或需要应用层加密的场景；需要安装应用及验证客户端版本 |
| SmartConfig / ESPTouch | 需要匹配的手机端实现 | 对本项目已有屏幕和网页没有明显便利优势，不作为默认路线 |

这是依据本项目“手机网页、免常驻电脑、两键操作”的需求作出的选择，不是所有产品的通用最优解。BLE 与 SoftAP 的取舍见[乐鑫统一配网文档](https://docs.espressif.com/projects/esp-idf/en/latest/esp32s3/api-reference/provisioning/provisioning.html)。

## 用户流程

1. **任意页面长按 BOOT 约 3 秒并松开**，进入配网。短长按与当前 1.2 秒帮助页手势需要重新分配，必须保证只触发一次；上电时持续按住 BOOT 仍会进入下载模式，提示只在运行时使用。
2. 屏幕显示带随机密码的设备热点二维码、热点名称和剩余配网时间。手机扫码加入；不支持扫码时可手工连接。二维码只包含本次设备热点凭据，绝不包含家庭 Wi-Fi 密码或服务账户密钥。
3. 尝试自动弹出配网页面；未弹出时打开 `http://192.168.4.1`。页面点击“开始配置”，屏幕与手机显示同一个短校验编号；用户核对后单击 BOOT 授权当前浏览器。由此代替手输网页配网码。
4. 手机选择附近的 **2.4 GHz Wi-Fi**、输入密码，点击“保存并连接”。先试连并反馈结果；已知旧网络保留，错误密码或超时可修改重试。账户和查询设置放入可选的“高级设置”，不挡住基本配网。
5. 获取路由器 IP 后保存新网络；页面分别显示“已连接路由器”“网络时间已同步”“服务查询结果”，不把获得 IP 当作所有服务均可用。点击“完成”关闭热点；成功后无人操作也自动关闭。下次上电直接连接已保存网络。

触发动作只是打开窗口，不会自动授权网页修改配置。IMU 转圈可作为将来的可选快捷入口，仍需手机配对和实体确认；它不是认证秘密。当前只读取加速度计用于方向判断，不能将其称为已支持绕重力轴的三圈识别。若增加完整转圈手势，需读取陀螺仪，验证旋转轴、正反方向、累计角度、时间限制及日常搬动的误触发。默认不要求用户旋转六圈。

## 并行联网与连接恢复

ESP32-S3 支持 `WIFI_MODE_APSTA`，现有固件配网时已经启用。正常使用只开 STA；进入配网才加开 AP，原有查询继续运行。**AP 与 STA 共用无线电和主信道**：加入不同信道的新路由器时，热点会跟随 STA 换信道，部分手机可能短暂断线；页面需自动重试，屏幕也要保留结果。不能承诺全程完全不中断。[官方 Wi-Fi 驱动说明](https://docs.espressif.com/projects/esp-idf/en/v5.5.6/esp32s3/api-guides/wifi.html#home-channel)

只修改 API key 或查询间隔时，不断开、重配 STA。更换家庭网络则不可避免会中断旧 STA 连接：候选网络先存在 RAM，获得 IP 后才提交持久化；约 45 秒失败则恢复旧配置。试连期间重启仍应使用之前保存的有效网络。

手机连接设备热点后可以访问本地配置页，**AP+STA 本身不代表手机也能通过设备上互联网**。互联网转发需要额外 NAPT 与 DNS 转发；当前未启用，默认也不为配网增加这一层。设备自身联网不需要 NAPT。[官方 SoftAP/STA 示例](https://github.com/espressif/esp-idf/tree/master/examples/wifi/softap_sta)

自动弹页参考本机 ESP-IDF v6.1 的 `examples/protocols/http_server/captive_portal`：局部 DNS 与 HTTP 探测重定向，另评估 DHCP Option 114 的手机兼容性。重定向不得劫持 HTTPS；DNS 服务只绑定设备 AP 接口，不能干扰 STA 的外部域名解析。自动弹页、Wi-Fi 二维码识别均须用真实手机验证，始终保留 IP 地址入口。[官方 Captive Portal 示例](https://github.com/espressif/esp-idf/tree/master/examples/protocols/http_server/captive_portal)

## 安全边界与要求

- 热点仅在首次启动的限时窗口或实体操作后开启。每次开启生成新的随机高强度密码；二维码随之更新，默认只允许一台手机接入。窗口到期、完成或取消后停止 AP、DNS、HTTP，并作废全部会话；即使还没有保存 SSID 也必须超时关闭。
- 网页配对需要当前窗口、AP 接口及实体确认，未配对前不能读设备状态、扫描附近网络或提交配置。短编号只供核对，真正浏览器会话使用至少 128 位随机秘密，不用短编号充当长期令牌；会话仅在本次窗口有效，限制尝试频率和请求体大小。
- 判断请求到达的本地接口，配置入口只接受 AP 目的地址；仅检查来源是否属于 `192.168.4.0/24` 不够。校验允许的 Host/Origin，不开放跨域 API；凭据不用 URL、二维码或日志传递，不使用第三方网页资源。
- 已保存的 Wi-Fi 密码、API key、access/refresh token 均不可读回，包括网页、USB 状态和错误日志。只提供“已设置”、替换和清除。家庭 Wi-Fi 明文密码只在本次输入与必要的设备运行内存中使用，持久化保护另见下文。
- WPA2 保护的是手机到热点的无线链路；普通 HTTP 页面**不等于应用层端到端加密**。本方案主要防止不知道临时热点密码的附近人员和未获授权的网页修改。能看见二维码、控制手机或接触设备的人不在这个保证内；限制一台客户端也不能替代加密或认证。
- 若要求在热点凭据暴露时仍保护配置内容，优先采用官方 Protocomm **Security 2（SRP6a + AES-GCM）** 和兼容客户端，不自行发明握手加密；这一安全等级会增加客户端要求。不能称当前自定义网页已经实现 Security 2。[官方 Protocomm 安全方案](https://docs.espressif.com/projects/esp-idf/en/latest/esp32s3/api-reference/provisioning/protocomm.html)
- 当前 `dashboard` NVS **未加密**，禁止声称能防拆机读取。硬件存储保护可使用 ESP32-S3 HMAC 派生密钥的 NVS 加密，但会占用并烧写 eFuse 密钥块；需单独核查现有 eFuse、备份与更新流程，不在普通配网改动中自动开启。[官方 NVS 加密文档](https://docs.espressif.com/projects/esp-idf/en/latest/esp32s3/api-reference/storage/nvs_encryption.html#nvs-encryption-hmac-peripheral-based-scheme)

## 实施前后的核实状态

当前已有：AP/STA 并行、随机但持久的热点密码、手输 8 位网页配网码、HTTP 配置、SSID/密码保存、断线重连和三个服务的查询适配。当前无 SSID 时热点不会按十分钟关闭；HTTP 配置服务也没有限制只从 AP 接口访问。

本设计新增、尚未实现或烧录：全局长按入口、每次窗口轮换密码、Wi-Fi 二维码、自动弹页、实体授权会话、AP 接口限制、失败回滚与统一超时。原有双按键、IMU 方向和已验证的整屏全刷须保留。

验收须覆盖：两种手机的扫码/自动弹页与手动入口；换信道重连；错误 Wi-Fi 密码回滚及试连中断电；未授权、跨接口、跨域、过期会话拒绝；已存秘密不可读回；配置 API key 不导致 STA 重连；配网期间查询与按键继续工作；完成或超时后热点和配置接口确实关闭。未实测项不记为通过。

# SD 音乐播放器（0.2.36）

将音频文件放在 SD 卡根目录的 `music` 文件夹，例如 `/music/歌曲.mp3`。使用现有 FAT32 卡；固件不会格式化。温湿度日志继续写到 `/EPaper/env/YYYYMMDD.csv`。

音乐页在温湿度页后面，也可从 HomeCraft 的设备显示页面选择“音乐”。上电自动读取目录，但不会自动播放。待机时每 60 秒重新检查；播放或暂停时先保留当前文件，停止后再更新目录。歌曲按文件名排序，读取该目录第一层最多 128 首，忽略隐藏文件、空文件和子目录。文件名最多 240 个 UTF-8 字节，常用简体中文可显示，少数字形可能缺失。

## 按键

| 手势 | BOOT | PWR |
| --- | --- | --- |
| 单击 | 下一首；正在播放时切歌 | 上一首；正在播放时切歌 |
| 双击 | 播放 / 暂停 / 继续 | 音量加 5 |
| 三击 | 离开音乐页，音乐继续 | 停止并回总览 |
| 长按 | 3 秒进入原 Wi-Fi 配网 | 1.2 至不足 3 秒松手：音量减 5；约 3 秒后松手：正常关机 |

音量范围 0–100，开机默认 90。暂停时换歌会停止在新选择处，双击 BOOT 开始播放。曲尾顺序播放下一首，最后一首结束后停止。正常关机先停止音乐并释放文件，再执行原 SD、网络与关机画面流程。PWR 持续按住 8 秒的硬件关机仍保留。音乐页的双击用于播放，不再触发额度读取或整屏全刷；清残影、旋转仍可通过 HomeCraft 操作。

## 音频范围

| 文件 | 内容与限制 |
| --- | --- |
| `.mp3` | MP3 |
| `.wav` | 常见 PCM WAV；输出转换支持 8/16/24/32 位整数、单/双声道 |
| `.flac` | 带 FLAC 文件头的 FLAC |
| `.aac` | ADTS AAC |
| `.m4a` | 官方解析器的 AAC / MP3 / ALAC；文件的 MOOV 信息必须在 MDAT 音频数据之前 |
| `.ogg`、`.oga`、`.opus` | Ogg Vorbis / Ogg Opus 容器；不支持无容器的 raw Opus |

仅处理无加密的本地音频。WMA、APE、受保护的音乐平台缓存、封面歌词和拖动快进尚未实现。不是所有同扩展名文件都使用支持的编码，损坏或不支持的文件会停下并显示错误。采样率检查范围 8–96 kHz、单/双声道；不表示所有码率/编码组合均已逐项实测。单喇叭将左右声道平均后输出，不增加数字增益。

## 实现与验证

使用官方 `esp_codec_dev 1.6.2` 和 `esp_audio_codec 2.6.2`，只开启 ES8311 播放，不启用麦克风。复用 GPIO41/42 I²C；I²S0 使用 MCLK13、BCLK14、WS47、DOUT48，PA39。IMU 仍以 I²C 轮询，不启用有冲突的 GPIO39 中断，拨轮 GPIO4/5/6 保持禁用。

播放期间暂时提高 CPU 上限到 160 MHz 并持有音频所需的电源锁；暂停/停止关闭功放和输出，恢复原 40–80 MHz / 自动轻睡配置和原 ALDO1 音频供电位。解码栈、歌曲表及大缓冲使用 PSRAM，SD 输入缓冲使用内部 DMA 内存；为硬件传输保留 64 KiB 内部内存。播放必然增加耗电，本轮未测整板电流或电池续航。

SD 仍由环境日志统一挂载，音乐持有读取租约，文件打开期间不卸载；日志写入出错后先通知音乐关闭，再卸载重试。未进行物理拔卡、异常掉电或坏卡实测。显示继续使用双 RAM 差分，状态/选曲/音量变化按原紧急合并刷新，播放时间每 10 秒发布一次；页面或方向变化才按原策略全刷。

0.2.36 实板用原创 3 秒片段验证了七种文件：MP3、PCM16 WAV、PCM24 FLAC、ADTS AAC、AAC M4A、Ogg Vorbis、48 kHz Ogg Opus，均解码并完成音频输出；暂停/恢复、顺序切歌、曲尾 EOS、停止时 PA 拉低/供电恢复和 CPU 设置回退已检查。测试文件完成后仅按固定名称和完整内容校验清理，原有文件保留。中文文件名与横竖屏布局采用真实绘图器的合成数据检查，用户的完整歌曲及实屏观感仍待实际使用确认。完整部署事实见 `3Inch7EPaper/artifacts/music-0236-validation.json`。

HomeCraft 同步更新到 0.2.36 以识别音乐页和新的页掩码；账户数据源、蓝牙 Security 2 及原绑定不变。本轮没有新增远程音频传输或任意文件接口。

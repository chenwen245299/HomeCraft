# HomeCraft 0.3.2

## DeepSeek Harness 同步对话去重

- 按日志中的会话、轮次、步骤和重试标识合并调用，同一对话同步到多台 Mac 后只统计一次。
- 最终结算替换同次调用的中间记录，真实重试独立计入；继承前缀和重复导入不重复累计。
- 首页、AI 用量页和支持中枢合计的显示端使用同一份去重结果；各机明细标为观测，不再作为独立消费相加。
- iCloud 只同步脱敏调用键、时间和用量数字，不同步对话正文或账号凭据。
- 旧版只有总数的记录等待调用明细后再纳入；数据冲突显示待核对，缺失值保持未知。

## 升级说明

- 所有参与统计的 Mac 都需更新，并继续使用同一个 HomeCraft iCloud 文件夹。同步需保留日志的会话与调用标识；重建标识的第三方导入尚未验证。
- 旧版仅支持 Harness 分机统计的屏幕，其 Harness 专页需配套固件；本次 App 更新不会自动刷写屏幕。
- 保留现有设置、设备绑定和用户数据；当前仍为 ad-hoc 签名，未经过 Apple 公证。
- 已完成 159 项软件回归与离线兼容检查；真实双 Mac 收敛及配套固件实屏仍待验证。

# HomeCraft 0.3.1

## 发布与更新

- 加入 App 内软件更新：自动检查新版、后台下载、查看更新说明，以及安装并重启。
- 下载完成后也可在退出 HomeCraft 时安装；检查和自动下载可在设置中关闭。
- 建立 GitHub Release 发布流程，统一生成 Mac 安装包、更新压缩包、校验文件和更新清单。

## 用量与日常使用

- 首页、AI 用量页和支持统一合计的墨水屏共用 HomeCraft 汇总结果。
- Codex 按账号去重；共享 Argus 文献库只计一次；DeepSeek Harness 按电脑来源合并，保留各来源明细。
- 新摘要缺少周/月字段时保留同周期有效统计，缺失值继续显示未知。
- 来源页显示各台 Mac 的最后更新时间；各台 Mac 需运行新版并选择同一个 iCloud 同步文件夹。
- 设置中可勾选登录 Mac 后自动启动，在菜单栏继续同步（macOS 13 或更新版本）。

## 升级说明

- 仅适用于 Apple 芯片 Mac，系统要求 macOS 12 或更新版本。
- 更新只替换 HomeCraft App，保留本机设置、设备绑定及 iCloud 文件；不会自动刷写硬件固件。
- 旧版首次升级需手动安装此版本，此后的版本可使用 App 内更新。
- 更新后如果 macOS 重新询问蓝牙权限，请允许 HomeCraft；已有设备绑定继续保留。
- 当前为 ad-hoc 签名，尚未经过 Apple 公证。

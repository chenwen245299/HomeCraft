# HomeCraft 0.3.5

## 修复

- DeepSeek Harness 按今日、本周、本月分别核对同步调用。同一调用数值相同、日期不同且仍属于同一周或月时，相应周期只计一次；某个周期有分歧时，仅该周期显示未知，保留其他周期的有效用量。
- Harness 显示具体受影响的周期，保存同机历史记录合并后的日期分歧，不再让笼统的冲突标记一直清空合计；从公开数字来源重建旧版不可恢复的派生冲突缓存，真实数值冲突仍保持未知。
- 修复大调用缓存被 32KB 配置上限拒读的问题。数字缓存使用独立有界读取和版本化文件，保留旧文件；普通配置与凭据仍使用原有大小和权限限制。
- 减少后台更新引发的重复重绘，系统标题栏仅在窗口尺寸或显示状态变化时调整。
- 统一窗口、GPU 画面与清屏背景为不透明绘制，去掉整幅不透明背景下多余的系统毛玻璃合成层；保留 App 内原有背景、半透明卡片与模糊外观，处理整窗或背景闪烁。

## 升级说明

- Mac App 为 0.3.5 / build 57，保留现有设置、设备绑定与用户数据，沿用原刷新频率；参与同步的各台 Mac 请更新到本版。
- 本次只更新 Mac App；闪烁的现场表现需在发生问题的窗口复核。

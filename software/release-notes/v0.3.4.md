# HomeCraft 0.3.4

## 修复

- 修复 DeepSeek Harness 跨 Mac 同步后一直显示“等待同步”的问题。同一调用的 Token 数和 UTC+8 日期一致、仅记录时间不同时只计一次；数值或日期冲突仍保留提示。
- 修复界面点击、滚动和页面切换卡顿。用量合并改为后台处理，界面直接使用已完成的结果，减少大量记录下的重复计算和内存复制。

## 升级说明

- Mac App 为 0.3.4 / build 54，保留现有设置、设备绑定和用户数据，沿用原刷新频率与统计口径。
- 参与同步的各台 Mac 请更新到本版。
- 本次只更新 Mac App，不刷写或变更屏幕固件。

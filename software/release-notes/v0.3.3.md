# HomeCraft 0.3.3

## 用量同步

- AI 用量采集、去重、汇总和跨 Mac 同步统一由 HomeCraft Mac App 完成，移除从屏幕读回机器来源缓存的旧路径。
- 配套屏幕只接收并显示 App 的最终结果，不再按机器或服务累加；缺少合计、周期不匹配或收到未知值时显示未知。
- 连接旧固件时，App 明确提示需要升级及尚未同步的功能。
- 保留 DeepSeek Harness 调用级去重和各 Mac 观测明细，仅同步脱敏标识、时间及用量数字。

## 小墨水屏配套固件 0.2.42

- 总览固定显示 Codex、Argus、DeepSeek Harness 三张卡片，数量、顺序和尺寸不再随读取结果变化。
- 等待同步、读取失败或数据未知时保留卡片和状态，缺失数值显示 `--`，不再从三张卡片缩成两张。
- 已绑定的普通数据模式固定每2秒广播，保留原配对、认证及差分刷新方式。

## 升级说明

- Mac App 为 0.3.3 / build 51，小屏固件为 0.2.42，两者独立升级；安装本次 Mac 更新不会自动刷写屏幕。
- reTerminal E1002 的 0.3.1 结果直显适配仍为候选，尚未完成实机部署验证。
- 保留现有设置、设备绑定和用户数据。

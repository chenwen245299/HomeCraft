# HomeCraft 0.3.6

## 修复

- 修正 DeepSeek Harness 实时跨机同步后的用量日期。自定义 iCloud 插件通过官方 Session.append 追加打开中的对话时，外层事件时间会变为接收时间；HomeCraft 现在优先读取与该笔用量数字完全匹配的原始 usage 记录时间，避免跨日、跨周或跨月导入把消费挪到接收日期。
- 为时间来源增加明确标记；相同调用、修订和数字合并时，原始用量时间优先于旧版保存的外层时间。保留必要的跨周期原始证据，经同步、缓存重载和重启后仍可纠正旧版日期；真实数值分歧继续保持未知。
- 日志扫描同时核对文件身份和状态变化，识别同步插件在保留长度和修改时间时替换的日志，不再反复使用旧解析结果。
- 使用版本化数字缓存和同步旁路文件保留时间来源，继续为旧版输出兼容文件；仅同步脱敏调用标记、时间与数字。
- 包含 0.3.5 的大调用缓存读取、按周期保留有效用量及窗口背景绘制修复。

## 升级说明

- Mac App 为 0.3.6 / build 58；保留现有设置、绑定、对话与用户数据。
- 参与用量同步的各台 Mac 均应更新。当前修复在 HomeCraft 中完成，不要求修改 iCloud 插件或关闭正在使用的 Harness 对话。

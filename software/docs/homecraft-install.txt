HomeCraft 0.3.1 build 49 · Apple 芯片 Mac · macOS 12+（自启动需 macOS 13+）
软件更新：家庭设置底部点“软件更新”，或菜单栏点“检查软件更新…”。默认自动检查并下载；就绪后可安装并重启，也可退出时安装。检查和自动下载均可关闭。0.3.0及更早版本需先手动安装本版；更新保留本机设置和设备绑定，不会自动刷写固件。
扫描不到广播不代表设备不在附近；若由另一台Mac连接，先在原电脑暂停同步。已有绑定无需重新配对。
多台设备：最多记住8台，各自用自己屏幕上的配对码绑定一次；HomeCraft读取一次官方用量，同时发给所有已连接的屏幕。可逐台暂停或在菜单全部暂停，暂停一台不影响其他设备。
天气：在主页点“天气”卡片设置，最多两个城市（默认新加坡），也可关闭；天气来自Open-Meteo，不按IP定位，只把城市名、天气摘要和明天的预报发到支持的屏幕，超过6小时未更新会从屏幕上清除。
待办：顶部“待办”进入，支持四象限（左上重要不紧急、右上重要且紧急）、当天时间线和月历；未完成的待办按象限颜色发到E1002（屏幕只显示标题）。每项可写详情（最多500字，只在Mac上显示）；象限底部的输入框回车直接添加，点“详细”可先设日期、时间和详情；按住标题拖到另一个象限即可改象限。在“自动化 → iCloud 同步”选择iCloud Drive里的HomeCraft文件夹后，各台Mac的待办会通过iCloud自动合并。
古诗与各位置温湿度：显示页可切换每日古诗（内置100首）；环境页点击位置卡片可单独查看该位置，“全部位置”恢复对比；“编辑位置”可命名并保存。曲线可选过去1/6/24/48小时，悬停查看同一时刻的温度和湿度，点击或拖动固定时间，左右方向键逐条查看，Esc或“返回实时”解除固定；缺少采样的区间留空。天气和“设备今日记录与其他来源”在曲线下方。
reTerminal E1002彩色屏需要配套0.3.0固件；3Inch7EPaper继续使用现有固件，不支持的功能（如天气）不会显示。
3Inch7EPaper屏（0.2.33起）：Codex保留5小时／周额度与进度条，新增“昨日”一行，显示官方昨日Token与同账号昨天最后记录的周额度已用百分比。缺失显示--，不能当作昨日新增消耗。

安装
打开 DMG，将 HomeCraft.app 拖到 Applications。更新前先从菜单栏退出旧版，再替换并打开；本机设置与蓝牙绑定保留。
更新后若macOS重新询问蓝牙权限，请点“允许”；已有设备仍沿用原绑定。
当前为本机 ad-hoc 签名，尚未 Apple 公证。若系统阻止打开，请使用“系统设置 → 隐私与安全性 → 仍要打开”，仅对确认来自本项目的安装包操作。
Apple 说明：https://support.apple.com/zh-cn/102445
关闭窗口后继续在菜单栏运行；“退出 HomeCraft”才停止。默认不开机自启；在“家庭设置 → 启动”勾选“开机自启动（登录 Mac 后）”立即生效，取消勾选即可关闭。自动启动后在菜单栏同步；若显示等待系统允许，点击“打开系统登录项”允许 HomeCraft。

iCloud Drive 同步
1. 两台 Mac 登录同一 Apple 账户，并启用 iCloud Drive。
2. 在“家庭设置 → iCloud 与来源”点击“选择同步文件夹”，在 iCloud Drive 新建或选择 HomeCraft 文件夹。
3. 另一台 Mac 选择同一个文件夹。App 每30秒交换文件，也可点“立即同步”。上传下载由 macOS 完成，可能稍有延迟。
文件夹里按内容分为“AI用量”“温湿度”“待办”三个子文件夹，每台Mac每天一份。旧版写的 HomeCraft-Data-v1、HomeCraft-Data-v2、HomeCraft-Todos-v1 新版只读取、不再写入；所有Mac都装上新版后可以删掉这三个旧文件夹。
同步账号用量数值、设备来源和已接收到的温湿度曲线。Mac/日期选择器可查看最近90天；更早的云端文件不会自动删除。
Codex 账号由官方 account/read 取得，只显示邮箱前1–3个字符加***；没有邮箱时用设备名。同一邮箱的账号统计取最新读数，绝不按Mac重复相加。不同账号各自保留。
DeepSeek Harness 的用量按电脑来源合并。当前两台 Mac 的 Argus 已由用户确认共用同步文献库，因此取最新有效汇总、只计一次，不相加；各机明细保留。Claude 上下文和 DeepSeek API 余额不算入 Token 消费。首页、用量页和所有支持 totals:1 的屏使用同一汇总口径。各台 Mac 都需换装本版，并在“iCloud 与来源”选择同一个文件夹；可在“汇总来源”核对最后更新时间，旧记录不会冒充今天。
云端读数标明“iCloud · 来源Mac”，本机自己的旧读数标为“本机缓存”；其他Mac的温湿度在“环境”页“设备今日记录与其他来源”里列出。温湿度曲线为设备回传的15分钟均值，不是SD逐分钟CSV副本；未接收的记录不会凭空补齐。
暂停同步保留本机与云端既有数据。若要清理，先在所有Mac暂停再处理文件，避免缓存重新上传。

账号与数据源
Codex 需本机已有官方 Codex CLI，并已登录；HomeCraft 只通过官方 app-server 读账号、额度与Token，不调用模型。卡片可检查CLI、刷新或选择可执行文件。
Claude Code 只接收官方 statusLine；Argus 只读其官方MCP汇总；DeepSeek只查询官方余额；DeepSeek Harness只读本机官方用量记录。使用这些本地数据源仍需对应客户端或本机配置。
“AI用量 → 刷新设置”可调整自动读取周期，默认30秒；DeepSeek余额有独立的最低查询间隔。官方未提供的当天Token保持未知。

EPaper
本次仅为软件更新，无需刷机；兼容原有设备固件。连接原来记住的设备即可。
新Mac首次添加：板子连接状态页双击BOOT，App重新扫描并选择EPair_设备，输入屏幕8位码，点击码框下方“安全连接”。每台Mac只认证一次，无需USB；换机时原Mac暂停、另一台连接。
温湿度30秒采样、SD每分钟记录；自动遥测每5分钟回传，手动采样立即回传。正常数值局刷，切页/方向变化全刷。

隐私
安装包不含个人缓存或凭据。登录令牌、API Key、蓝牙绑定、本机CLI路径均不进入同步文件夹。完整Codex邮箱不保存，跨Mac使用散列标识去重。
独立运行时本机资料位于 ~/Library/Application Support/HomeCraft；在开发项目中运行则沿用项目私有配置。iCloud仅在主动选择文件夹后启用。

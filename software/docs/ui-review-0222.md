# HomeCraft 0.2.22 界面检查

本轮只修改 Mac 软件，未扫描/连接 BLE、未使用 USB、未编译或烧录固件。数据源、账号识别、iCloud 合并和设备认证规则保留。

## 已处理

- [x] Codex 操作栏：更新时间在按钮右侧，同一行；短时间默认只显示时分，悬停可看完整日期与秒。失败状态使用“尝试于”，避免被理解为成功更新。
- [x] 操作稳定：检查、刷新按钮保留固定宽度，读取中不会横向跳动；官方用量读取不再因无关的传感器控制而禁用。
- [x] 数字与进度条：5小时、周额度用相同高度的数值区，进度条对齐；未知额度不画成满额或0。
- [x] 服务头部：图标、加粗名称、脱敏账号与账号入口合并，不另占一行。完整来源放在悬停提示，云端回退保留来源标记。
- [x] 页面留白：减少内容顶部重复标题及多余空行；全量刷新的上次时间收进操作区域。
- [x] 显示页：主卡片铺满可用宽度，清除残影收在标题右侧；未连接时有连接入口，实际控制保持禁用。
- [x] 家庭设置：家庭名和房间并排；修改后才允许保存，未保存状态明确。刷新、iCloud、Codex分为独立入口，不在同一长表单里堆叠。
- [x] 刷新设置：直接进入刷新表单，常用选项减少为30秒/1分钟/5分钟/30分钟，自定义30秒–120分钟保留。保存与当前状态同排。
- [x] 弹窗尺寸：短弹窗按内容收起，需要滚动时才出现滚动条；标题、关闭键固定在内容外。返回上级时重置布局高度，避免沿用较小子页的高度。
- [x] 设置返回：子设置有左上角返回，返回保留父页与原设备标签；关闭或Esc退出整层弹窗。
- [x] 首页点击区域：整个连接提示卡可点；房间标题也可进入房间。箭头位置按实际文本宽度计算。
- [x] 长名称：家庭、房间、侧栏与设备名按宽度省略，不覆盖右侧操作或信号强度；侧栏/设备完整名可悬停查看。
- [x] 连接表单：未选设备时禁用配对输入，按钮位于输入框正下方且同宽；已连接时避免重复认证；未连接时暂停按钮禁用。输入8位码仍必须明确点击后才能连接。
- [x] 自动化/探索：原展示条目变为真实页面或设置入口，不能点击后无反应。
- [x] iCloud：状态与标题、最后交换时间与按钮分组同排；账号卡统一宽度，不引入新材质。实际云端含义不变。
- [x] 图标交互：标题栏、返回、关闭、侧栏等补充悬停、指针和可访问标签。状态提示可关闭，完整错误可悬停查看。
- [x] 快捷键：⌘, 打开设置、⌘S保存修改；AI用量与温控页的⌘R沿用各自的手动刷新。无连接时不发设备命令。
- [x] 样式统一：原深色玻璃、橙色重点、圆角/字体继续由共享主题管理；未新增浅色卡片或独立配色。

## 检查方式

82项Rust测试通过，包含实际组件的宽窄布局、按钮同排与加载宽度、设置返回、真实目的页、未连接控制禁用及长名称回归。原有图表悬停/固定选中、配对必须显式点击、小提示可关闭等测试继续通过。Clippy检查所有目标为零警告。

正式构建通过 `--render-ui-preview` 产生270张样例，覆盖850×620、1100×780、1440×900，两种背景，7个主页面以及设置/刷新/连接/账号/设备弹窗和空数据/错误/读取状态。图像位于 `3Inch7EPaper/artifacts/homecraft-0222-ui/`，附控件位置清单；样例不代表真实用量。

`software/tools/test_homecraft_native_ui.py` 使用独立 `--ui-preview` 实际打开macOS窗口，检查7个导航页、设置返回、两种窗口尺寸及关闭隐藏/重新显示。此模式完全不启动后台，不访问真实账户、蓝牙或iCloud，不保存用户设置；检查后退出预览实例。结果见 `3Inch7EPaper/artifacts/homecraft-0222-native/native-ui-validation.json`。

安装包为 `software/dist/releases/HomeCraft-0.2.22-macos-arm64.dmg`。最终签名、打包白名单与测试结果见 `3Inch7EPaper/artifacts/homecraft-0222-ui-validation.json`。原来的运行中App未替换或重启；用户安装后需退出旧菜单栏实例再打开新版。仍为ad-hoc签名，未Apple公证。

## 实测边界

本轮验证软件操作与布局；设备命令在组件测试中只核对请求，不向硬件发送。另一台Mac的iCloud文件传输、真实BLE操作与系统文件选择器中的用户选择仍需按需验证，不把离线样例当作已完成实机测试。
